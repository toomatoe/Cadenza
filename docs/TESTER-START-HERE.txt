Welcome to Cadenza!

1. Extract the whole ZIP using Windows "Extract All".
2. Open the extracted folder and double-click Cadenza.Desktop.exe.
3. Keep all the files together. You do not need to install .NET, Rust, or VS Code.

This build is for 64-bit Windows 10 (build 19041+) and Windows 11.
If Windows reports a missing Visual C++ runtime dependency, install Microsoft's
supported x64 Visual C++ Redistributable:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/

Early builds are unsigned and Windows may warn or block them. Only run a build
from the release you intended to download; do not disable Windows security.

Open Settings to connect Spotify. You currently need a Spotify developer app's
Client ID and registered loopback redirect URL. See README.md for setup details.
Native streaming is experimental and requires Spotify Premium.

Queue contents stay in memory and clear when you close or disconnect.
For an update, close Cadenza and extract the new ZIP into a fresh folder.
Saved preferences and sign-in live outside the application folder.

Report issues at https://github.com/toomatoe/Cadenza/issues
Include the release version, Windows version, and steps to reproduce.
Please leave tokens and other credentials out of reports.
